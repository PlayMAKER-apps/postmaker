# Install and use PostMAKER

PostMAKER is a web app. It can also be installed as a Progressive Web App (PWA), which opens in a standalone window and can start offline after one successful online visit. It is not an App Store or native mobile app. A future native app may reuse the same editor components, but it is outside this release.

## Italiano — iPhone e iPad

1. Apri l'URL di PostMAKER in **Safari** mentre sei online.
2. Tocca **Condividi**.
3. Tocca **Aggiungi alla schermata Home**.
4. Se disponibile, attiva **Apri come app**.
5. Tocca **Aggiungi**.
6. Apri PostMAKER dalla nuova icona e attendi il caricamento completo prima di provarlo offline.

I nomi e la posizione dei comandi possono cambiare in base alla versione di iOS. Se **Aggiungi alla schermata Home** non appare, scorri l'elenco delle azioni di Safari. L'installazione non rende permanente lo spazio del browser: esporta regolarmente il backup JSON.

Per esportare una grafica, tocca **Share or download PNG**. Quando iOS supporta la condivisione del file, si apre il foglio Condividi; in caso contrario parte un download. Il selettore file di iOS consente di scegliere immagini da Foto o File secondo i permessi concessi.

Su schermi piccoli tutti i campi sono disponibili in pannelli richiudibili. Il posizionamento preciso dei livelli usa controlli numerici ed è più comodo su uno schermo grande.

## English — iPhone and iPad

1. Open the PostMAKER URL in **Safari** while online.
2. Tap **Share**.
3. Tap **Add to Home Screen**.
4. Enable **Open as Web App** when that option is available.
5. Tap **Add**.
6. Open PostMAKER from its new icon and let it finish loading before testing it offline.

Command names and positions can vary between iOS versions. If **Add to Home Screen** is missing, scroll through Safari's action list. Installation does not make browser storage permanent; export JSON backups regularly.

Tap **Share or download PNG** to export a graphic. PostMAKER opens the iOS share sheet when file sharing is supported and falls back to a download. The iOS picker can offer Photos or Files according to the permissions you grant.

All form controls remain available in collapsible panels on small screens. Precise layer placement uses numeric controls and is more comfortable on a larger display.

## Android

1. Open PostMAKER in Chrome while online.
2. Open the browser menu and choose **Install app** or **Add to Home screen**.
3. Confirm the installation, open the new icon and wait for the first complete load.
4. Test offline mode only after that online load.

Menu wording varies by browser and Android version. JSON backups remain the recovery path if site data is cleared.

## PC and Mac browsers

In Chrome or Edge, open PostMAKER and use the install icon in the address bar or the browser menu's **Install PostMAKER** command. Safari on macOS may offer **Add to Dock**. Firefox can use the web app in a normal tab but may not offer standalone PWA installation.

## Use without installing

Open the PostMAKER URL in a supported browser and work in the tab. Installation is optional. The first visit requires a network connection, local projects use IndexedDB in that browser profile, and private or incognito sessions can remove data sooner. Export a JSON backup before clearing browser data, changing browser profiles or moving to another device.
