# PostMAKER 0.2 draft

This branch adds the offline-capable editor MVP and the public WebMAKER club-data adapter. It is not a hosted release. The web client supports Manual mode, validated public JSON import, a club Brand Kit, multiple graphics, versioned template layers, shared matches, local autosave, project backup and PNG export. The desktop app remains future work.

The public club contract is owned by `playmaker-schema` as `club-public-0.1`; WebMAKER exports selected publishable fields without changing TagMAKER's JSON or the existing site CSV/YAML formats. Browser integration and screenshot regression tests remain open release gates.
